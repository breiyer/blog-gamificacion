# 🎮 GamificaCode — Blog sobre Gamificación en la Enseñanza de la Programación

Blog académico para la electiva **Gamificación en Educación** (Maestría en Educación, Corporación Universitaria Iberoamericana).

Aborda el **constructo conceptual de la relación entre gamificación y educación**, aplicado a la enseñanza de la programación, e incluye un **quiz gamificado interactivo** con puntos e insignias.

## 🌐 Sitio publicado

👉 https://breiyer.github.io/blog-gamificacion

## 🧩 Contenido

- ¿Qué es la gamificación? (Deterding et al., 2011)
- Gamificación y educación: el constructo conceptual
- Los elementos del juego (dinámicas, mecánicas, componentes)
- Gamificación en la enseñanza de la programación (gincana Harry Potter)
- Quiz gamificado interactivo
- Referencias (APA)

## 🛠️ Tecnología

- [Astro](https://astro.build/) — sitio estático rápido
- JavaScript para el quiz interactivo (sin dependencias)
- Despliegue automático a GitHub Pages vía GitHub Actions

## 💻 Desarrollo local

```bash
pnpm install
pnpm dev      # servidor de desarrollo en localhost:4321
pnpm build    # genera el sitio en dist/
pnpm preview  # previsualiza el build
```
